
# **INFINI-TOE**

### An infinite 3-by-3 Tic-Tac-Toe game for 2 players, created in Unity 6

---

### **RULES**

Players take turns placing their X and O tokens, starting with the Blue X side. Once a player has placed 3 tokens, their next move removes the oldest piece, so that each player only ever has 3 pieces placed at a time.

The game continues until a player obtains 3 tokens in a row.

### **CONTROLS**

Place tokens by clicking into the respective cell on the Tic-Tac-Toe board.

Player turn automatically switches after each token is placed.

Once a player has placed 3 tokens, the oldest piece will change to a darker color on their following turn to signify it will removed when they place their new token.
